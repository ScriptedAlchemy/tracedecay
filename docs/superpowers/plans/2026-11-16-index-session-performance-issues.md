## Review focus

1. Admission cancellation and capacity release race, including closed release channels: Task 1 `saturated_history_cancellation_does_not_reenter_or_lose_release`.
2. Equal directory timestamps, ignored compressed rollouts, and a restart with a partially acknowledged import: Task 3 `restart_preserves_committed_history_without_false_complete`.
3. Old progress producers arriving after retry/remount, and idle polling concealing a stalled writer: Task 4 `progress_restart_fences_old_work_and_idle_polls`.
4. Same-length source mutation, wrong extent/root and interrupted/overlapping proof publication: Task 5 `failed_successor_proof_preserves_only_authenticated_parent_extents`.
5. Equal generation names in different projections, shared packed ancestry and live-reader retirement: Task 7 `packed_successor_retention_preserves_scoped_live_readers` (L2-owned retention is a merge gate, not an L3 rewrite).
