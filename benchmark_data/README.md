# Benchmark data and provenance

This directory contains benchmark workloads, fixtures, runner scripts, and
recorded results. Cargo benchmark source is in `benches/` and in crate-local
`benches/` directories.

Current scripts and manifests use `benchmark_data/` paths. Captured historical
results may still show `benchmarks/`. Those paths record the repository layout
at capture time and do not point to the current directory.
