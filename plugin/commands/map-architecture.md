# Map architecture

Map the whole repository, or `$ARGUMENTS` when it names a directory. Follow the
bundled `code-health` skill, focusing on module distribution, public surfaces,
dependency structure, cycles, coupling, and depth as the requested map requires.

This command is read-only. Return a useful module map with evidenced dependency
hotspots or boundary violations and their practical risk.
