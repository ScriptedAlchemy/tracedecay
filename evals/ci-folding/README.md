# CI folding measurements

The hosted warm-worker experiments have been retired. Their recorded JSON
measurements remain historical evidence; they do not establish current CI
latency or cost. See `docs/ci-folding-2026-09-28.md` for the experiment history
and `docs/hauler-ci.md` for the current manager.

`replay.py` and its arrival/baseline/treatment inputs remain available for the
queue replay benchmark. The privileged experiment workflows and their runtime
scripts are removed; old dispatch commands in the historical report no longer
apply.
