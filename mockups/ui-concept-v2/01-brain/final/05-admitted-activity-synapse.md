# Admitted activity becomes synapse

## User job

See what TraceDecay is actually doing now: which exact project, repository,
worktree, agent, or artifact an admitted event touched, and how that activity
relates to the stable registry.

## Product behavior

- A synapse begins only when the dashboard receives an admitted activity event
  with a stable event identity, timestamp, family, and touched identity.
- The exact touched project blooms; energy may traverse one or more relations
  only when each hop has evidence from the repository, worktree, session,
  agent, task, code, or Delivery projection. Decorative inter-project firing
  is forbidden.
- Heat is temporary and decays independently of the persistent project body.
  Siblings stay dark unless the event actually touched them. Hover, focus,
  loading, connectivity, and selection never masquerade as activity.
- Selecting the pulse opens the exact source event/transcript/table row and
  can drill into Loom, Sessions, Agents, Work, Code, or Delivery. A missing or
  ambiguous source leaves an honest gap.

## Evidence and reasoning boundary

An event fact and touched identity may be `EXACT`; an explicit persisted agent
message may be `EXPLICIT`; a correlated code or task relation may be
`INFERRED` or `AMBIGUOUS`. Private chain-of-thought is always unavailable and
is never animated as if observed. The exact activity table exposes source,
grade, admission state, timestamp, touched identities, and supported hops.

## Acceptance gates

Reduced motion replaces travel with a static highlighted path and timestamp.
Keyboard users can follow the same pulse and evidence route. At 200% zoom the
event inspector and table reflow independently from the scene. Dense bursts are
time-bucketed with counts and can be expanded; no events are silently dropped.

## Production authorities

The admitted dashboard activity projection owns event and admission truth.
Project, repository, worktree, session, agent, task, code, and Delivery
authorities own their identities and relation edges. The shared scene may
render the pulse, while React/DOM owns the event inspector and exact fallback.
See [`IMPLEMENTATION.md`](../../IMPLEMENTATION.md).
