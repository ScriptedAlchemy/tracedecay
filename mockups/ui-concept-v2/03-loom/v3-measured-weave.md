## Intent

Open `/loom` after a thread page and coverage information are available.

## Visible state

Recorded, open, and unknown ends remain distinct; only a loaded LCM page is represented.

## Supported interactions

- Depicted: recorded/open strands, selected thread, paginated causal crossings, loaded-page playback metadata, source coverage, and freshness.

## Truth boundary

This is a `CONCEPT / SYNTHETIC` lookbook plate, not runtime evidence. It establishes no production data, authority availability, counts, health, freshness, persistence, or control. Any unavailable production path remains visibly unavailable.
