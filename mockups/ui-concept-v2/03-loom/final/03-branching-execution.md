# Loom 03 — Branching execution

- **Asset:** `03-branching-execution.png`
- **Lifecycle:** `current`
- **Boundary:** `CONCEPT / SYNTHETIC DATA`

## User job

Understand where a parent delegated work, what each subagent did in parallel, and how results returned to the main story. The neural weave is the provenance model: curves encode real spawn, handoff, and rejoin relationships rather than decoration.

## Production authorities

- Agents owns parent/subagent identity and evidenced spawn/handoff/rejoin parentage; Sessions/LCM owns session bounds and exact transcripts; admitted hook/event records own execution events.
- Work owns task identity, delegation targets, and transitions; local Git/Code owns file, diff, commit, symbol, and test evidence; Delivery owns PR/outcome cross-links.
- The deterministic layout projection allocates stable branch lanes from authenticated parentage and time. Provider state is read-only, and private reasoning remains unavailable.

## Entry and visible state

Expanding a branch from the journey reveals the parent lane, spawn node, child lane, child events, and any evidenced result/handoff/rejoin. Nested agents repeat the pattern. Unrelated branches compress to preserve context; the minimap retains the full loaded-page shape.

## Interaction model

- Expand/collapse at parent, workstream, or branch level; focus path-to-root or path-to-outcome.
- Muted collapsed branches retain their counts and evidence summary.
- Search and keyboard traversal locate agents, tasks, files, events, and unresolved evidence.
- An accessible branch tree/table is always available and uses the same selection, counts, and evidence classes.
- Focused paths meet contrast requirements in dark and reduced-luminance themes; muted context never becomes indistinguishable from unavailable evidence.

## Evidence and honesty

Spawn/handoff/rejoin edges require exact or explicit support. Inferred relationships are separately styled and explain their basis; ambiguous identity remains unresolved. Missing transcript pages, stale source data, and unavailable private reasoning are not filled in.

## Scale and accessibility acceptance

Keyboard branch navigation, reduced motion (including reduced-motion branch reveals), exact tree/table/transcript fallbacks, focus contrast, and 200% zoom are mandatory. Dense-real-data tests include nested fan-out, absent handoffs, and branches that never rejoin. The visible `CONCEPT / SYNTHETIC DATA` boundary remains.
