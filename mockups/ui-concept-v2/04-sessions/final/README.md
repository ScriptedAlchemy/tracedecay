# Sessions final state set

This folder is the authoritative Sessions implementation reference. Sessions combines a temporal overview, an exact virtualized session index, and a persisted-evidence inspector while keeping transcript coverage and source availability honest.

All pictured content is **CONCEPT / SYNTHETIC DATA**. It is an interaction reference, not evidence that a provider transcript, token count, or Git relation exists in production.

## Required product contract

- Persisted transcript, source availability, coverage, pagination, redaction, and transport state are independent authorities.
- Branch, worktree, commit, agent, task, Code, Loom, and Delivery links preserve evidence grade and stable identity.
- Private chain-of-thought is unavailable by design; only visible persisted artifacts may be shown.
- Keyboard, reduced-motion, 200%-zoom, dense-data, and exact table/transcript/event fallbacks are release acceptance gates.
