# PR journey overview

## User job

See how a selected PR came into existence before reading individual hunks.

## Product behavior

- A left-to-right temporal field begins with the human objective and proceeds through planning, investigation, decisions, implementation, verification, review, CI, and delivery.
- Agent and subagent work branches in time and space, then hands off or rejoins the delivery spine.
- Nodes are selectable semantic episodes, not decorative activity.
- Start or Continue review enters the full review workspace at the next unreviewed episode.

## Scale and access

Semantic zoom moves from outcome to workstream, agent group, agent, and event. A minimap, density compression, branch bundles, and exact tree/table fallbacks preserve orientation for long histories.
