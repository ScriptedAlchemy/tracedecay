# PR journey overview

## User job

See how a selected PR came into existence before reading individual hunks.

## Product behavior

- A left-to-right temporal field begins with the human objective and proceeds through planning, investigation, decisions, implementation, verification, review, CI, and delivery.
- Agent and subagent work branches in time and space, then hands off or rejoins the delivery spine.
- Nodes are selectable semantic episodes, not decorative activity.
- Start or Continue review enters the full review workspace at the next unreviewed episode.

## Scale and access

Semantic zoom moves from outcome to workstream, agent group, agent, and event. A minimap, density compression, branch bundles, and exact tree/table fallbacks preserve orientation for long histories.

## Truth boundary

The journey is a source-backed projection, not a reconstruction of private chain-of-thought. Nodes distinguish exact events, explicit persisted claims or decisions, inferred relations, ambiguous attribution, and unavailable evidence. Named attention sources replace generic risk scores.

## Access gates

- Keyboard navigation traverses semantic episodes, branch bundles, minimap landmarks, Start or Continue review, and source drill-downs in temporal order.
- Reduced motion replaces branch travel and replay previews with static revealed paths, selected-node treatment, and textual chronology.
- At 200% zoom, the journey enters a focused horizontal viewport while legends, controls, and episode detail reflow outside it.
- Exact tree, event-table, transcript, and diff fallbacks preserve chronology, parentage, source identity, and review destinations.

## Production authorities

- Work supplies the human objective and planned task graph; Sessions supplies persisted messages, summaries, event time, and transcript availability.
- Agents supplies spawn, subagent, handoff, and result attribution; local Git supplies branches, worktrees, commits, and exact changed code.
- Code supplies symbol and semantic-impact relationships; review, CI, release, and generation-freshness projections supply independently typed outcomes.
- The journey projection preserves stable source identities and the `exact`, `explicit`, `inferred`, `ambiguous`, or `unavailable` evidence grade for every episode and edge.
