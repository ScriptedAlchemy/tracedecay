# Code final state set

This folder is the authoritative implementation reference for Code. The Code workspace turns TraceDecay's indexed source graph into a navigable semantic cortex while keeping exact source, symbol, relationship, diagnostic, and test evidence one action away.

The plates are interaction references, not runtime proof. All pictured names, counts, freshness values, and health states are synthetic. A shipping implementation must bind every visible claim to the selected repository snapshot and render stale, partial, unavailable, ambiguous, or denied authorities explicitly. The structural-comparison board is an approved composition direction; its internal rectangles and edge counts are deliberately not an exact geometry specification, as detailed in its brief.
