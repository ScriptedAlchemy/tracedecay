# Code 02 — Structural comparison

- **Image:** [Concept board](02-structural-comparison.png), lower-right frame.
- **Boundary:** CONCEPT / SYNTHETIC DATA; illustrated counts are not measurements.

## User job

Recognize a repository's structure and inspect how a refactor changes it without
having to relearn its shape. Retain the structural atlas and churn view alongside
the semantic cortex. This board also illustrates the related Loom encounter flow;
its Loom authority is [Work proximity](../../03-loom/final/08-work-proximity.md).

## Comparison contract

Use an explicit pair of revisions and identical scope. Preserve region identity
and layout across both panes, or show a disclosed union layout for added/deleted
regions. Synchronize selection, pan and zoom. Region size and each layer have a
named measure, coverage, and source; missing evidence is not a zero value.

Keep dependency edges, path churn, byte-identical files, forwarding layers and
diagnostics separate. Seven-day churn is activity, not bad code. Byte-identical
fixtures or vendored files are not evidence of unnecessary implementation.
Allow explicit source-class filters and retain their scope in the comparison.
Use exact revision/source pivots to explain any claimed reduction in forwarding
or coupling. A single cleanliness score would hide the distinctions this view
exists to reveal.

## Production authorities and remaining boundary

Git supplies revision and change identity; the Code index supplies structural
relationships and coverage. The imported atlas already demonstrates churn,
exact duplicates, and one forwarding comparison. A general revision comparison,
semantic duplication and dead-facade interpretation require additional measured
evidence. The image's illustrative 12-to-4 label is not proof of those features.
The generated panes are a composition study, not an exact geometry specification:
their internal rectangles and edge counts do not precisely match. Implementation
must derive both panes from the same layout and actual revision relationships,
not reproduce those discrepancies or the repeated comparison label.

## Acceptance

Both panes keep the selected region recognizable, disclose additions/deletions,
and expose exact source evidence. Provide keyboard navigation and a tabular
comparison, reduced motion, readable 200% zoom/reflow, and explicit unavailable
states for unindexed revisions or missing measures.
