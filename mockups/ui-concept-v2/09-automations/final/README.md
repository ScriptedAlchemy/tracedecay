# Automations final state set

This folder is the authoritative implementation reference for Automations. Automations combines scheduler status, managed jobs, skills and permissions, run outcomes, receipts, artifacts, retries, and integrity evidence in one auditable ledger.

The plate is an interaction reference, not runtime proof. Its identities, counts, timing, outcomes, and artifact details are synthetic. No control may appear successful unless it invokes the real production scheduler authority and returns a durable receipt.
