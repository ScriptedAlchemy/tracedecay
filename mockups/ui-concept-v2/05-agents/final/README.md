## Required product contract

- Parent/subagent delegation, handoff, rejoin, task, work-product, and outcome links retain stable identity and evidence grade.
- Independent usage, hierarchy, token, Work, and failure authorities never collapse into one fabricated readiness state.
- Hundred-plus-agent histories use deterministic bundles, semantic zoom, branch search, focus-plus-context, and exact virtualized fallbacks.
- Keyboard, reduced-motion, 200%-zoom, dense-data, and exact tree/table/event fallbacks are release acceptance gates.
