# `tracedecay-dashboard-api` split seams

Mover output for the one-shot crate split
(`docs/superpowers/plans/2026-07-31-one-shot-crate-split.md`).

`src/dashboard/` (26 457 lines, 43 files) moved here; `src/dashboard/assets.rs`
stayed in the root crate because its bundle is generated by the root
`build.rs` into `OUT_DIR` and included with `env!("OUT_DIR")`, which only
resolves inside the crate that ran that build script. `src/dashboard.rs` is now
a shim: `pub(crate) use tracedecay_dashboard_api::*;` plus
`pub(crate) mod assets;`.

Per split doctrine this crate does **not** compile standalone yet. Every
remaining error is `E0432`/`E0433` on a `crate::<root module>` path — the
modules this crate reads that have not been extracted yet. They are cataloged
below so the lead can repoint them mechanically at integration.

Status at hand-off: `cargo check -p tracedecay-dashboard-api` → **212 errors**
(170 × E0433, 42 × E0432). All of them are unresolved root-module paths; there
are zero type errors, so the catalog below is exhaustive.

## Resolved during the move

### MCP coupling — inverted (no longer a seam)

`crate::mcp::server::RetainedProjectGraph{Request,Future,Resolver}` was the only
real MCP dependency (6 production references, all of one injected
`Option<…>` field on `DashboardState`). The contract now lives in
[`src/project_graph.rs`] in this crate — its sole consumer — and
`src/mcp/server.rs` re-exports it:

```rust
pub(crate) use tracedecay_dashboard_api::project_graph::{
    RetainedProjectGraphFuture, RetainedProjectGraphRequest, RetainedProjectGraphResolver,
};
```

Every root call site (`src/mcp/server.rs`, `src/mcp/server/construction.rs`,
`src/mcp/tools/handlers/{mod,dashboard}.rs`, `src/daemon.rs`) is unchanged: the
MCP server and daemon keep *supplying* the resolver, the dashboard keeps
*consuming* it. **This crate now has zero code references to `crate::mcp`.**

Note: the moved `RetainedProjectGraphRequest` constructors still call
`crate::worktree::git_common_dir` / `crate::branch::current_branch` — see the
kernel seam row below.

### Visibility

All 491 `pub(crate)` items in the moved files became `pub`; the root shim's
`pub(crate) use …::*` restores the original root-crate visibility, so no root
or integration-test import changed.

## Open seams

### 1. Embedded assets (root-pinned, needs a decision)

`src/lib.rs` (`router_with_active_application`) still names `assets::app_index`,
`assets::app_static`, `assets::app_spa_fallback` — 3 references, marked
`// SEAM(assets)` in place. Options, in preference order:

- **(a)** the root crate builds an `axum::Router` holding the three SPA routes
  and passes it into `router()` / `run_until_shutdown*()`, which `.merge()`s it
  after `.with_state(runtime)`. Costs one added parameter on 5 public
  signatures (`router`, `run`, `run_until_shutdown`,
  `run_until_shutdown_for_tests_with_host_admission`, `run_until_shutdown_inner`)
  plus their root/integration-test call sites.
- **(b)** add an injected SPA-asset provider field to `DashboardState`,
  mirroring the existing `project_graph_resolver` field. No signature churn,
  but `DashboardState` has no `Default` and is constructed explicitly in
  several places.

Not decided here because option (a) ripples into test files owned by other
movers.

### 2. Sessions test module

`src/lib.rs` keeps
`#[cfg(test)] #[path = "../../../src/sessions/lcm/dashboard_fixes_tests.rs"]`.
The path was repointed to reach back into the root tree so the coverage is not
silently dropped; the sessions mover is extracting `src/sessions/` into
`tracedecay-sessions`, so the lead should point this at the sessions crate (or
relocate the file into this crate's `tests/`).

- **`crate::config` (41 refs, 30 of them `config::PinnedUserDataDir`)** — the

  dashboard takes them as injected values.

  `settings_api.rs`, `lib.rs`.

### 4. Feature forwarding

The crate declares `token-counting` (→ `dep:tiktoken-rs`) and `test-transport`
to match the `#[cfg(feature = …)]` blocks in the moved code. The root crate
forwards both (`Cargo.toml`). `lite`/`full`/`production` do not reach this
crate.
